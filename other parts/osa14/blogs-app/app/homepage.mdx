# Welcome to Blog APp

This is a **modern blogging platform** built with Next.js, featuring user authentication, blog post management, and a clea, intuitive interface.

## Features

- **Create and Manage Blog** - Write and publish your thoughts
- **User profiles** - Personalized user pages
- **Authentication** - Secute login and registration
- **Comments** - Engage with blog posts

## Getting Started

To start exploring:

1. [Register](/register) for a new account
2. [Login](/login) to access your dashboard
3. [Create a new blog post](/blogs/new)
4. View [all blogs](/blogs) and [users](/users)

Built using Next.js, React, and Drizzle ORM.
